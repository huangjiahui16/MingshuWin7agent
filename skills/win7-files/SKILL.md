# Win7 文件整理

## 先看清再动手
1. `list_dir` 列目录（带大小/时间），别急着删。
2. 判断"能不能删"只看三条：空文件、明确的临时后缀（.tmp/.bak/.old）、用户点名的。
3. 删除走备份：先 `write_file` 把清单写到 logs/，再 `run_cmd` 用 move 移到备份目录，
   **不要直接 del**（Win7 没有回收站 API，删了就没了）。

## 批量改名安全流程
1. 先列出将改的完整清单，给用户确认（含新名字）。
2. 用 `run_cmd` 逐条 ren，命名里避免 `& | > < ^` 这些 cmd 元字符。
3. 中文文件名必须整体加双引号，否则 cmd 会按 GBK 截断。

## 重复文件
按 (大小, 文件名) 先粗筛，再对候选做 MD5 比对（`certutil -hashfile "路径" MD5`），
不要凭文件名就断言重复。

## 硬限制
- 路径长度 260 字符。目标路径接近 240 就要提醒用户。
- 机械硬盘上大批量读写会卡死系统：单次操作不超过 200 个文件，分批做并报告进度。
